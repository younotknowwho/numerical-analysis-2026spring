Hilbert矩阵  $` {H}_n = [h_{ij}] \in \mathbb{R}^{n \times n} `$ ，其元素  $` h_{ij} = 1/(i+j-1) `$ ，分别对  $` n = 2, 3, 4, \cdots `$ ：

1. 计算  $` \mathrm{cond}({H}_n)_\infty `$ ，分析条件数作为  $` n `$  的函数如何变化。

2. 令  $` {x} = (1, 1, \cdots, 1)^{\mathrm{T}} \in \mathbb{R}^n `$ ，计算  $` {b}_n = {H}_n {x} `$ ，然后解线性方程组  $` {H}_n {{x}} = {b}_n `$ （可用 MATLAB 的 `\` 或其他），解为  $` \bar{{x}} `$ ，计算残差向量  $` {r}_n = {b}_n - {H}_n \bar{{x}} `$  和误差向量  $` e_n = \bar{{x}} - {x} `$ 。

3. 对每个  $` n `$ ，观察  $` \bar{{x}} `$  分量有效数字位的变化，分析原因。当  $` n `$  为多大时相对误差达到 100%  （即  $` \bar{{x}} `$  连一位有效数字也没有了）。
